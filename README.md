# 🌌 Neon Void
Аркадный неоновый 2D-шутер на Python и Pygame с системой комбо, визуальными эффектами частиц и локальной таблицей лидеров.

## 🎮 Управление
* **WASD** — Перемещение корабля
* **Мышь** — Прицеливание
* **ЛКМ** — Стрельба
* **Пробел** — Неуязвимый рывок (Dash)
* **Клавиатура** — Ввод имени на экране Game Over
* **Enter** — Сохранение рекорда
* **R** — Перезапуск игры
* **Esc** — Выход из игры

## 🚀 Быстрый запуск
1. Клонируйте репозиторий:
git clone
[https://github.com/ваш-username/neon-void.git](https://github.com/ваш-username/neon-void.git)
cd neon-void
1. Создайте и активируйте виртуальное окружение:
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate
2. Установите зависимости и запустите:
pip install -r requirements.txt
python main.py
